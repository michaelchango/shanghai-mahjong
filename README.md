# 上海敲麻（单机版）

一个**单文件 HTML** 的上海敲麻麻将游戏：1 个真人 + 3 个机器人，手机上用浏览器直接打开就能玩，无任何外部依赖、无需联网。

## 运行

把 `index.html` 传到手机（微信/邮件/网盘均可），用浏览器打开即可。

- iOS：Safari 打开 → 可「添加到主屏幕」
- Android：Chrome 打开 → 可「添加到主屏幕」

> 更新版本后如果界面没变化，多半是浏览器缓存了旧文件，清一下缓存即可。

## 规则

### 敲麻核心

| 规则 | 说明 |
|---|---|
| **不敲不能胡** | 必须先报听（敲）才有资格胡牌 |
| **敲后锁定** | 不能换牌、不能吃碰，摸什么打什么 |
| **有和必和** | 敲定后别人打出你的听牌，自动胡 |
| **有杠必杠** | 敲定后摸到可杠的牌，系统自动杠 |
| **漏胡** | 放弃胡某张牌后，动牌之前不能再胡同一张 |

### 牌型与番数

| 牌型 | 番 | 牌型 | 番 |
|---|---|---|---|
| 碰碰胡 | 1 | 清一色 | 3 |
| 混一色 | 1 | 清碰 | 4 |
| 混碰 | 2 | 风一色 | 4 |
| 七小对（可选） | 2 | 风碰 | 8 |
| 垃圾胡（平胡） | 0 | | |

**附加番**：门清 +1、无花果 +1、大吊车 +1、杠上开花 +1、海底捞月 +1、地胡 +8、天胡 +8

### 底（花）与算分

- **底 = 起底 + 花数**。花牌来源：季/花牌每张 1 花、**中发白每张算 1 花**、数牌明杠/暗杠 1/2、风牌刻子/明杠/暗杠 1/2/3
- **得分 = 底 × 2^番 × 每花分值**，单份封顶 N 勒（1 勒 = 10 花）
- **自摸**：三家各付一份；**点炮**：点炮者付一份（一炮多响各付一份）
- **开宝**：骰子为豹子或 1·4 点，本局得分与封顶 ×2
- **荒番**：上一局流局，得分与封顶 ×2^荒番数，有人胡后荒番 −1

## 界面说明

| 区域 | 内容 |
|---|---|
| 四家面前（各自视角，由近到远） | 手牌区 → 花+吃碰杠区 → 牌河区 |
| 名牌 | `底N×番N` + `N分`（实时计算） |
| 听牌标记 | 敲定后手牌/牌背上出现「听」圆章 |
| 吃碰来源 | 牌组中间那张牌上的箭头，指向打出这张牌的那一家 |
| 桌心 | 剩余牌数、四家风位、骰子点数、开宝/荒番/封顶标签 |
| 骰子下方 | 最近三手出牌记录 + 「全部手牌记录」 |
| 结算后底部 | 「查看结算」「下一局」两个常驻按钮 |
| 右上角「记」 | 本轮所有已结算牌局的历史记录，可回看任意一局 |

## 设置

右上角 ⚙ 可调整：底、每花分值、封顶勒子、允许吃牌、七小对、垃圾胡、自动敲、机器人速度、重开一桌。

历史记录按「轮」累计，**只有开始新一轮（或重开一桌）才会清零**。
